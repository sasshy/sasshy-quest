Siriから仕事タスクを追加

「Siri、サッシーに仕事を追加」→ 依頼を話す → AIが整理 → SASSHYに保存 → 登録内容を読み上げます。

例：「田中さんから電話。取引先Aに月曜15時までに部品の見積を送る。送料も確認」

最初の設定

SupabaseのEdge Functions → Secretsに OPENAI_API_KEY を設定します。既存のタスク受付キー SASSHY_TASK_INGEST_TOKEN をショートカットで使います。秘密のキーをチャットや共有リンクに貼らないでください。

音声の文字起こしはiPhone、文章整理はOpenAI APIで行います。API利用料はChatGPT Plusとは別です。音声ファイルは送らず、今回の文字起こしだけを送信します。

ショートカットを作る

名前は「サッシーに仕事を追加」。次の順にアクションを追加します。

  1. テキストを音声入力：言語は日本語。
  2. UUIDを生成：1回の依頼につき1つ生成。
  3. 辞書：idempotency_key にUUID、transcript に音声入力の結果を入れます。
  4. 辞書をテキストに変換し、ファイルを保存で「Shortcuts/SASSHY-last-request.json」に上書き保存します。送信が途切れたときの再送用です。
  5. URLの内容を取得：下記URL、方法はPOST。ヘッダに Authorization = Bearer （タスク受付キー）、Content-Type = application/json。本文はJSONで、辞書と同じ2項目を指定します。
  6. 返り値の辞書から ok を取得。もし trueなら message をテキストを読み上げる。それ以外は error を表示・読み上げます。エラーを「登録できた」と読み上げない設定にしてください。
{
  "idempotency_key": "（UUIDを生成の結果）",
  "transcript": "（テキストを音声入力の結果）"
}

通信失敗・結果不明なら、保存したJSONを読み込み、同じ2項目を再送してください。新しいUUIDを作ると別の依頼になります。登録済みの受付番号なら、AIを再実行せず登録済みの内容を返します。

未対応の再通知

音声で追加した仕事は再通知ON。平日9〜18時（日本時間）、1時間おきです。期限時刻から、時刻なしは期限日の17時から、期限なしは登録1時間後から通知します。夜間・週末は次の平日9時以降になります（祝日は判定しません）。

SASSHYのタスクを開き「仕事の期限・相手・再通知」で期限・相手・依頼元を修正できます。1時間／1日延期、通知停止もできます。作業開始・完了・ゴミ箱移動で停止し、再開した場合は状態に応じて通知が戻ります。変更は同期後に通知サーバーへ反映されます。

iPhoneではホーム画面に追加したSASSHYの「設定」で通知を有効にし、テスト通知を確認してください。iPhoneの集中モードや通信状態により届く時刻が遅れる場合があります。

最初に試すこと

「テスト先に明日15時までに見積を送る」と話して、読み上げとSASSHYの受信箱の内容を確認。同じ保存済みJSONを再送して1件のままか確認。テストタスクの再通知をOFFにして保存・同期してください。
